# Мобильное приложение «КФБ Инвест»

21 октября 2026. После мобильного прототипа начата реализация React Native с существующим Go API. Исходный [файл Figma](https://www.figma.com/design/spMjzIpFoU4aLcdq37MLZW/Untitled?node-id=0-1) не изменялся.

## Дизайн

Сохранены пять нижних вкладок: Главная, Рынок, Портфель, Заявки, Профиль. Светлый серо-голубой фон, белые скруглённые карточки, тёмно-синие действия, поля от 44 px. На телефоне интерфейс занимает экран; web ограничен 440 px.

Новая версия получает данные API вместо иллюстративных цен, графиков, комиссии 0,2% и локального демосчёта. Валюта берётся из счёта; локальный тестовый счёт использует KZT. Учётная стоимость портфеля обозначена отдельно от рыночной котировки.

## Первый этап разработки

| Сценарий | Реализация |
| --- | --- |
| Авторизация | Login, опциональный TOTP, refresh, logout, auth/me |
| Сессия | SecureStore на устройствах, память в web, очистка кеша |
| Счета | Выбор счёта, права из API, изоляция CLIENT |
| Главная/портфель | Cash, позиции, учётная стоимость, скрытие сумм |
| Рынок | Instruments/market, поиск, категории, избранное |
| Инструмент | Last/bid/ask, валюта, размер лота, шаг цены |
| Заявка | LIMIT/DAY, Decimal, три шага и отдельная отправка |
| Заявки | Статус сервера, исполненный объём, причина отказа, отмена |
| История | Журнал доступных денег выбранного счёта |
| Профиль | Пользователь, информация о счёте, настройки, выход |
| Уведомления | Серверный список и пустое состояние |

Ответы валидируются Zod, server state хранится в TanStack Query с ключами пользователя/счёта. Есть таймаут, отмена запросов и ошибки с повтором. Заявки опрашиваются каждые 5 секунд, деньги/портфель/котировки — каждые 15 секунд. Риски и комиссии остаются на сервере.

В Go исправлены необходимые для мобильного сценария ошибки: повторный client_order_id ищется по брокеру выбранного счёта с проверкой параметров; неуспешный денежный резерв откатывается до сохранения отклонения заявки. Блокировка счёта сериализует повторы. При конфликте данные другой заявки не возвращаются.

## Среда

Android Studio установлен из официального пакета Google через winget. Подготовлены JDK, SDK, нативный Expo-проект и Pixel 8/API 36 с WHPX.

Локальный Go-стенд `sbis-mobile-dev` имеет собственные Postgres/Redis и API только на 127.0.0.1:18080. Данные синтетические, адаптеры mock, биржевой шлюз отключён. Команды: [mobile/README.md](../mobile/README.md).

## Следующие этапы

1. WebSocket с восстановлением и сверкой пропущенных событий.
2. История рыночных котировок и рыночная оценка портфеля.
3. Согласованные банковские переводы, KYC, документы и push.
4. Staging: частичное исполнение, положительная отмена, предторговая оценка комиссии. Физические Android/iOS: экранный диктор, шрифт, фон, сеть, TOTP, SecureStore.
5. Замечания зависимостей, staging, подпись и проверка release перед публикацией.

`mobile/design-evidence/` относится к прошлому демопрототипу. Новая версия проверяется с реальным API локального стенда; промышленный запуск ещё не выполнялся.

## Визуальное выравнивание · 22.10.2026

По просьбе пользователя удалены служебная полоса окружения, подписи API/REST/потока и пояснения о токенах. Название на приветствии и в конфигурации приложения — «КФБ Инвест». Приветствие, группировка рынка, карточки заявок и группы профиля сверены с визуальными фреймами исходной Figma. Пользователь выбрал визуальную сверку: Figma MCP требует Editor и не выдал параметры слоёв.

Источник данных разработки остаётся тестовой КФБ localhost:8080 через существующий Go API. Ограничения доступа и режим просмотра не изменялись. Цены и история доходности не рисуются при отсутствии данных.
