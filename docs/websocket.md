# WebSocket между интерфейсом и API

Endpoint: `/v1/realtime/ws` (`ws://localhost:18080/v1/realtime/ws` локально).
Вход, обновление токенов и восстановление пароля используют HTTP; запросы
авторизованного приложения идут по одному WebSocket-соединению.

Первое сообщение в течение 10 секунд: `{"type":"auth","token":"<access_token>"}`.
Сервер отвечает `{"type":"ready","upstream_connected":true}`. Токен нашего
пользователя отличается от серверного `KFB_GATEWAY_TOKEN` и не передаётся КФБ.

Запрос: `{"type":"request","id":"1","method":"GET","path":"/v1/positions","watch":true}`.
Для команд передаются JSON `body` и при необходимости `headers` с
`Idempotency-Key`, `X-Request-ID`, `X-Trace-ID`. Ответ:
`{"type":"response","id":"1","path":"/v1/positions","status":200,"data":{"items":[]}}`.
Запросы исполняются существующими маршрутами с их правами и фильтрами клиента.

`watch:true` разрешён для GET `/v1/positions`, `/v1/market`, `/v1/orders` и
`/v1/market/{id}/book`. Первоначальный ответ содержит полный снимок. После события
сервер отправляет `{"type":"snapshot","path":"/v1/positions","status":200,"data":{"items":[]}}`.
Клиент заменяет кэш, включая пустые списки. Рыночные события обновляют рынок и
стакан, события позиций — позиции, события заявок — заявки и позиции.
Каждые 20 секунд сервер также проверяет сессию, отправляет статус соединения и
сверяет подписанные снимки. Команда `{"type":"unwatch","path":"..."}` отменяет
подписку. При смене инструмента предыдущий стакан отписывается.

Переподключение имеет задержку 1–30 секунд. Подписки восстанавливаются и получают
новые снимки. Незавершённые команды при обрыве не повторяются автоматически:
их результат мог уже сохраниться. Клиент получает ошибку с указанием неизвестного
результата. Неверный или отозванный токен вызывает `{"type":"unauthorized"}` и
закрытие соединения. Проверяются Origin, лимит соединений и размер сообщения (1 MiB).

КФБ по-прежнему подключается к backend через gRPC mTLS с `KFB_GATEWAY_TOKEN`.
REST API остаётся доступным для внешних клиентов и резервной связи backend с КФБ.
