# Проверка первой версии

21 октября 2026. Проверена экспортированная веб-версия React Native, а не отдельная HTML-имитация.

## Автоматические проверки

- `npm run typecheck` — успешно.
- `npm test` — 3 теста, 3 успешно: комиссия и резерв покупки, освобождение резерва после отмены, резерв бумаг для продажи, недопустимое количество/цена и нехватка средств.
- `npm run export:web -- --max-workers 2` — успешно, финальная сборка в `dist/`.
- `npx expo export --platform android --output-dir dist-native --max-workers 2` — успешно, Hermes bundle и ресурсы. APK не создавался.

## Проверка через интерфейс

- 390 × 844: главная, рынок, поиск, ввод и подтверждение заявки, портфель, отмена.
- 360 × 800: профиль, длинные подписи, нижняя навигация. `document.body.scrollWidth === innerWidth === 360`.
- Поиск по отсутствующему инструменту показывает пустое состояние; сброс возвращает пять инструментов.
- Нулевое количество показывает сообщение об ошибке и оставляет пользователя в форме.
- Покупка 5 МАНАС по 1 250 с показывает сумму 6 250 с, комиссию 12,50 с и итог 6 262,50 с.
- Финальная кнопка создания выключена до выбора подтверждения деморежима.
- Созданная демозаявка появилась в активных; свободный остаток уменьшился с 70 000 до 63 737,50 с.
- После подтверждённой отмены остаток восстановился до 70 000 с, резерв стал 0 с.
- Скрытие сумм в портфеле маскирует общий итог, доход в сомах, остатки и количество/стоимость позиции.
- После исправления перехода на следующий шаг заголовок «Проверка заявки» расположен на y=32 px. Стрелка назад возвращает к вводу с сохранением 5 бумаг и цены 1 250.
- В финальной production-сборке при проверке `dev.logs` с уровнем `error` ошибок не найдено.

## Что ещё не проверено

Физические устройства, нативная клавиатура, системное увеличение шрифта, VoiceOver/TalkBack, реальная авторизация, серверные ошибки, realtime и платежи. Полного аудита доступности не проводилось. Политика релиза и замечания npm audit описаны в README мобильного проекта.
